# Roadmap (Public-Safe)

This roadmap describes public-safe goals only. It intentionally excludes internal model logic, private datasets, betting systems, operational thresholds, and production secrets.

## Replay Engine Evolution

- Expand deterministic schema coverage for additional artifact types
- Strengthen normalization rules for time, numeric, and textual fields
- Improve lineage primitives for governance workflows

## Governance Evolution

- Improve manifest provenance fields and audit schema versioning
- Add stronger validation profiles for different replay classes

## Observability Goals

- Continue improving low-cardinality metrics and deterministic log shapes
- Strengthen traceability from API requests to replay run identifiers

## Non-Goals

- Prediction logic or betting logic
- Private datasets or scraped sources
- Production operational thresholds
- Credential-bearing configuration
