# Security Policy

## Supported Versions

This project currently maintains the latest `main` branch only.

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please do not open a public issue.

Send a report to:

- `security@example.invalid`

Include:

- A clear description of the issue and potential impact
- Minimal reproduction steps or proof of concept
- Any relevant logs (redacted)

Public-safe posture is a core requirement:

- Do not include secrets in reports.
- Do not include private datasets or payload artifacts.
